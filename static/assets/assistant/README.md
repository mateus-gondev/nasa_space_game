# Assistente NOVA

As 12 imagens originais foram fornecidas pelo usuário no arquivo `assistente-pixel-art.zip`. Foram copiadas sem alteração; o ZIP não continha instruções ou scripts.

O componente `nova.js` é compartilhado pelo treinamento e por Marte. Exibe uma imagem, um balão com texto acessível e um botão opcional de ação. As variações são agrupadas em orientação (1–3), ciência (8–10), comemoração (4, 6, 11) e atenção (5, 7, 12). São escolhas de apresentação, não emoções detectadas nas imagens.

A animação troca três imagens lentamente e para, respeitando a preferência de reduzir movimento. Repetir a mesma dica não reinicia a animação nem atualiza o anúncio acessível. No mapa, é possível recolher o balão e tocar no assistente para reler a dica.

O fundo escuro das imagens é integrado ao painel azul usando CSS, sem apagar ou gerar pixels. A origem e os direitos das imagens permanecem os do material fornecido.
